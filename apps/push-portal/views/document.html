คู่มือการใช้งาน Push Notifications

เอกสารอธิบายวิธีรับการแจ้งเตือนการบ้านผ่านเบราว์เซอร์ และข้อมูลสำหรับนักพัฒนา

สำหรับนักเรียน / ผู้ใช้งานทั่วไป
1
เข้าหน้า Push Notify
กดเมนู Push Notify ในแถบนำทาง หรือเข้าที่ / ของ Push Portal
ต้องเปิดผ่าน HTTPS เท่านั้น — ตรวจสอบว่า URL ขึ้นต้นด้วย https://
2
กด "รับการแจ้งเตือนการบ้าน"
เบราว์เซอร์จะแสดง Dialog ขออนุญาต กด Allow / อนุญาต
ถ้ากด Block ไปแล้ว → ไปที่ Settings ของเบราว์เซอร์ → Site Settings → Notifications → เปิดสิทธิ์
3
เลือกทีมที่ต้องการรับการแจ้งเตือน
หลังสมัครสำเร็จ จะมีรายการทีมให้เลือก เลือกทีมที่คุณสังกัดแล้วกด บันทึกทีมที่เลือก
ถ้าไม่เลือกทีมใด = รับการแจ้งเตือนจากทุกทีม
4
รับการแจ้งเตือนอัตโนมัติ
เมื่อครูส่งการบ้านใหม่ผ่าน Admin Portal จะมี Notification ขึ้นที่เบราว์เซอร์ทันที แม้คุณจะอยู่หน้าอื่น
การแจ้งเตือนทั้งหมดจะถูกบันทึกใน กล่องแจ้งเตือน ในหน้า Push Notify
ข้อกำหนดของเบราว์เซอร์
เบราว์เซอร์รองรับ?หมายเหตุ
Chrome (Desktop/Android)รองรับแนะนำ
Firefoxรองรับ
Edgeรองรับ
Safari (macOS 16.4+)รองรับบางส่วนต้องเพิ่ม PWA ก่อน
Safari iOSไม่รองรับApple ยังไม่เปิดให้ Web Push บน iOS

Web Push จำเป็นต้องใช้งานผ่าน HTTPS เท่านั้น
การเปิดผ่าน HTTP จะทำให้เบราว์เซอร์ซ่อน Push API ออกทั้งหมด แม้เป็น Chrome ล่าสุด
API Reference (Internal)

Push Portal รันบน Port 8082 — ทุก API ที่มี X-Push-Secret ต้องการ header ยืนยันตัวตน (ตั้งค่าใน .env)

MethodPathคำอธิบายAuth?
GET / หน้าสมัครรับการแจ้งเตือน ไม่ต้อง
GET /document หน้าคู่มือนี้ ไม่ต้อง
GET /api/vapid-public-key คืน VAPID Public Key สำหรับ browser subscribe ไม่ต้อง
GET /api/teams รายการทีมทั้งหมด (Proxy จาก teamService) ไม่ต้อง
GET /api/subscribers/count จำนวน subscription ที่ active อยู่ทั้งหมด ไม่ต้อง
POST /api/subscribe บันทึก PushSubscription object + teamIds ที่เลือก ไม่ต้อง
DEL /api/subscribe ยกเลิก subscription โดย endpoint ไม่ต้อง
POST /api/push/send Broadcast push ไปยัง subscribers ที่ตรงกับ teamId X-Push-Secret

ตัวอย่าง POST /api/push/send

POST /api/push/send HTTP/1.1 X-Push-Secret: <PUSH_SECRET จาก .env> Content-Type: application/json { "title": "การบ้านใหม่: คณิตศาสตร์ - แบบฝึกหัด 5", "body": "กำหนดส่ง: 22 มิ.ย. 2569", "url": "https://hwnotify.example.com/homework", "teamId": "c2869774-7f24-441a-b317-01277df5d7fb" }
